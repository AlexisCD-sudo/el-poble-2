# THE FORGOTTEN VILLAGE

A 3D atmospheric exploration game set in an abandoned European medieval village.

## Vision
Explore a mysterious abandoned village at night, discovering its streets, houses, church, forest and inhabitants.

## Visual style
- 3D low-poly environments
- Modern pixel-art textures
- Medieval European architecture
- Atmospheric night lighting and fog
- First-person exploration with a handheld flashlight

## Technology
- Three.js
- JavaScript
- Blender
- Vite
- GitHub Pages
